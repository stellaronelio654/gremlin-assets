# Gremlin.OS Asset Vault — Version 2

**47 image assets** collected into one public static gallery, including the original 3 avatars, 10 new standalone illustrations, and 34 individually separated stickers.

## Publish to GitHub Pages

1. Extract this ZIP on your computer.
2. Upload **the contents of this folder**, not the folder itself, into the root of https://github.com/stellaronelio654/gremlin-assets (use a public repository).
3. Preserve the `assets/` folder structure. `index.html`, `site.css`, and `app.js` must be at repository root.
4. In GitHub → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
5. Visit https://stellaronelio654.github.io/gremlin-assets/ after deployment.

## Existing repository note

If you already uploaded V1, replace `index.html`, `app.js`, `site.css` and upload the new `assets/` directories without removing your original avatar files. GitHub's browser uploader can be used for the files and their folders (drag the extracted contents).

## Use images in JanitorAI

Open an image card, click **Copy image URL** or **Copy CSS**. Each URL is derived from the current site location and the relative file path.

Example (after publishing):

`https://stellaronelio654.github.io/gremlin-assets/assets/icons/stickers/paw-print-large.png`

All repository files are public. Do not upload private art or personal photos.
